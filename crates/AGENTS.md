# CRATES — Rust Workspace

## OVERVIEW

10 library crates + 1 CLI binary (`agnetd`). All share `neunode-core` as foundation. Flat `src/*.rs` structure — no `mod.rs` subdirectories.

## STRUCTURE

```
crates/
├── neunode-core/       # Shared types, Kind taxonomy, config, errors (0 internal deps)
├── neunode-crypto/     # Ed25519, secp256k1, EIP-712, hashing → core
├── neunode-identity/   # DID, keyring, agent card, documents → core, crypto
├── neunode-storage/    # RocksDB 20 CFs, moka cache, stores → core, crypto
├── neunode-p2p/        # libp2p gossipsub, KadDHT, peer scoring → core, crypto, identity
├── neunode-feed/       # Sigchain, events, schemas, filters, topics → core, crypto, identity, storage
├── neunode-token/      # Balance, staking, decay, mint/burn → core, crypto, identity, storage
├── neunode-reputation/ # 5-factor scoring, attestations → core, crypto
├── neunode-bounty/     # State machine, escrow, review, verification → core, crypto, identity, storage, feed, token, reputation
├── neunode-inference/  # OpenAI compat, router, provider, settlement → core, crypto, identity, storage, feed, token
└── agnetd/             # CLI binary (clap 4) → all 10 crates
```

No cycles. `neunode-core` is the sole leaf (no workspace-crate dependencies).

## CONVENTIONS

- Entry point: `lib.rs` (libraries) or `main.rs` (agnetd). No `mod.rs`.
- Errors: `thiserror` derive in each crate's `error.rs`. Never `anyhow` in library crates.
- Tests: inline `#[cfg(test)] mod tests` at bottom of each source file.
- Property tests: `proptest` crate (used in crypto, core).
- Shared deps managed via `[workspace.dependencies]` in root `Cargo.toml` — use `workspace = true`.
- `ts-rs` derive on structs shared with TypeScript SDK. Generated to `bindings/` per crate.

## NOTES

- `neunode-bounty` is the most complex crate (lifecycle.rs 1359 lines, state_machine.rs 801 lines).
- `agnetd` has 11 command modules (`cmd_*.rs`) + dashboard TUI (`cmd_dashboard.rs` 667 lines).
- Integration tests live in top-level `/tests/` (separate crate), not per-crate.
- `bindings/` dirs are generated by `cargo test` via `ts-rs` — listed in `.gitignore`.
